# 🚀 TradingDiscidence — 交易风险管理终端 v5.0-alpha

**面向加密货币合约交易的专业风险控制与交易日志系统。**

以风险控制为核心，提供从**开仓前计算 → 持仓监控 → 平仓记录 → 统计分析 → 复盘优化**的完整交易闭环工具。专为期货/合约交易者设计，帮助建立纪律化交易系统。

## ✨ 核心功能模块

### 1️⃣ 仪表盘 Dashboard
- **今日盈亏**：实时显示当天未平仓交易的累计盈亏
- **本周胜率**：基于历史已平仓交易的胜率统计
- **在仓风险**：当前持仓的保证金占用、强平价风险、风险敞口
- **连亏计数**：检测当日连续亏损笔数，触发熔断机制
- **资金曲线**：Canvas 绘制的账户权益变化折线图
- **强平预警**：实时展示未平仓仓位的强平价风险提示

### 2️⃣ 开仓计划 Planner
**仓位计算器（核心功能）**——以风险金额反向推算理想仓位：

| 参数 | 类型 | 说明 |
|------|------|------|
| 交易品种 | 选择器 | BTC/ETH/SOL/GOLD |
| 入场价格 | 数值 | 必填，用于计算止损距离 |
| 本金 | 数值 | 账户权益（USDT） |
| 风险比例 | 下拉（0.5%-10%）| 单笔最大可承受亏损占比 |
| 止损价格 | 数值 | 必填，决定止损距离 |
| 杠杆 | 选择器（0x-125x）| 影响保证金需求 |
| 方向 | 做多/做空 | 必须选择 |
| 止损执行类型 | 市价/限价 | 影响成交确定性 |
| 止盈价 | 选填 | 计算盈亏比 |

**输出结果：**
- 💰 建议仓位（USDT）
- ⚖️ 所需保证金
- 📊 盈亏比（R:R）
- 🔴 止损触发损失金额
- ⚠️ 强平价警示（当止损价接近强平价时红色警告）

**进阶功能：**
- **分批建仓**：支持 2-3 批入场，每批独立设入场价和分配比例，自动计算加权均价
- **多止盈规划**：TP1/TP2/TP3 三级止盈，自动计算每阶段的盈亏比
- **盈亏比反推**：设定目标 R:R，自动推算止损价或止盈价
- **开仓前检查清单**：8项风控合规检查（风险比例、止损距离、强平安全、连亏熔断、盈亏比、保证金、入场理由、心态评分）

### 3️⃣ 交易日志 Journal
- **完整交易记录**：时间、品种、方向、入场价/止损价/止盈价、仓位、状态、策略框架、入场原因、情绪标签、R倍数
- **软删除**：删除后有5秒撤销窗口
- **批量操作**：多选后批量删除、批量导出JSON
- **导入导出**：支持 JSON 导入、CSV 导出
- **智能过滤**：按品种、方向、策略、状态、时间段、盈亏多维度筛选
- **快速预设**：一键应用"今天""本周""亏损单""持仓中"等过滤条件
- **权益曲线图**：可视化累计盈亏趋势，标注最高点和回撤

### 4️⃣ 风控中心 Risk Control
实时监控系统健康状态：

| 监控项 | 说明 |
|--------|------|
| 账户概览 | 总余额、已占用保证金、可用余额、风险敞口、强平总价值 |
| 日亏损监控 | 当日盈亏进度条，超出设定上限告警 |
| 回撤监控 | 当前回撤幅度、最大回撤阈值告警 |
| 强平价监控 | 所有未平仓仓位的强平价与止损距离对比 |
| 风险集中度 | 按品种、方向、时段的风险分布热力 |
| 交易频率与连赢/连亏趋势 | 近期交易频次与连续盈亏走势 |

**熔断机制：** 当日连续亏损 ≥3 笔时禁止新仓位，强制冷却。

### 5️⃣ 统计分析 Analytics
全方位绩效评估：

**综合指标：**
- 已平仓交易数、胜率、总盈亏、平均盈亏

**风险质量指标：**
- 盈亏比（平均盈利÷平均亏损绝对值）
- 期望值 = 胜率×平均盈利 − 败率×平均亏损（核心！正值才值得持续）
- 利润因子 = 总盈利÷总亏损绝对值（>1.5合格，>2优秀）
- 最大回撤（权益从峰值到谷底的最大跌幅）

**执行质量指标：**
- 目标达成率（达到预设止盈的比例）
- 均实际R:R（实际回报相对于风险）
- 预判偏差（实际盈亏与入场预判是否相符）
- 平均持仓时长（验证策略节奏是否匹配）

**持仓管理指标：**
- MAE（最大不利偏移）、MFE（最大有利偏移）、MFE/MAE比率

**可视化图表：**
- 资金曲线（Canvas）
- 策略绩效明细表
- 情绪胜率明细表
- 亏损原因分布饼图
- MAE/MFE散点图
- 平仓类型分布
- 多维拆解（品种×方向×时段）

### 6️⃣ 复盘中心 Review
深度分析找出改进空间：

- **亏损原因分布**：追涨杀跌、扛单、过早止盈等根源统计
- **策略形态排名**：按不同形态（上升三角、双底、RSI背离等）胜率排序
- **情绪关联分析**：恐惧/贪婪/报复/无聊/过度自信对绩效的影响
- **执行纪律跟踪**：入场时的评分与实际结果的关联

## 🔒 风险控制体系

### 硬规则限制
1. **单笔风险上限**：默认不超过账户2%（可自定义）
2. **保证金约束**：新开仓位保证金 ≤ 可用余额 × 50%
3. **强平安全线**：止损价必须在强平价之上，否则红色预警
4. **连亏熔断**：连续亏损 ≥3 笔时禁止开仓，需手动确认重置

### 动态调整机制
- **连亏降仓**：连续亏损 ≥3 笔时，自动将仓位降至60%，强制风控
- **心态评分**：入场前要求心态评分≥3（平静/良好），低于此标记警告
- **品种专属止损比例**：可对不同品种设置差异化止损容忍度

## 📊 核心计算公式

```
风险金额     = 本金 × 风险比例%
止损距离     = |入场价 - 止损价|
名义仓位     = 风险金额 × 入场价 / 止损距离
保证金       = 名义仓位 / 杠杆（杠杆为0时为现货）
盈亏比       = |止盈价 - 入场价| / |入场价 - 止损价|（空方向取反）
强平价(多单) = 入场价 × [1 - (1 - MMR) / 杠杆]
强平价(空单) = 入场价 × [1 + (1 - MMR) / 杠杆]
加权均价     = Σ(批次价格 × 批次占比) / Σ(批次占比)
```

> MMR = 维持保证金率（默认值可在设置中调整）

# 🖼️ GlassStudio — 毛玻璃图片编辑器

**一款专注于毛玻璃美学风格创作的简约图像合成工具。**

通过拖放上传图片，添加毛玻璃卡片、文字标题等元素，自由编辑位置、尺寸、样式，最后导出高清 PNG。

## ✨ 功能特色

### 创作元素
| 元素类型 | 特点 |
|----------|------|
| 🎯 毛玻璃框 (Glass) | 高斯模糊 + 饱和度调节 + 背景透明度 + 边框光感 |
| 🃏 深色卡片 (Card) | 深色半透明遮罩 + 内阴影 |
| ✍️ 文字框 (Text) | 独立文字层 + 字体大小/颜色/阴影/对齐自定义 |

### 编辑特性
- **拖拽移动**：精确像素级定位，支持方向键微调
- **缩放调整**：通过角点手柄自由拉伸，最小约束保护
- **多层操作**：上下移层、锁定元素、复制粘贴
- **文本双击编辑**：双击进入文字修改模式
- **撤销/重做**：完整的命令历史栈（Ctrl+Z/Y）
- **滤镜预设**：一键应用白色/深蓝/暖橙/通知气泡等模板样式
- **本地字体支持**：上传 TTF/OTF/WOFF 字体供文字层使用

### 导出能力
- **高分辨率导出**：支持 1x~4x 分辨率倍率导出
- **Canvas 转 PNG**：高质量渲染输出
- **项目保存**：保存工程文件为 `.glassproj`（JSON格式），随时继续编辑

## 🎨 界面布局

# 🔧 使用说明

## 本地运行

1. **直接打开 HTML 文件**：浏览器访问 `file:///.../index.html`（TradingDiscidence）或 `file:///.../GlassStudio.html`（GlassStudio）
2. **无需服务器**：纯静态页面，完全本地运行
3. **首次使用**：打开后自动加载本地存储的数据，如为空则创建新项目

### TradingDiscidence 使用流程

```
开始 → 填写本金 → 计算仓位 → 检查清单 → 保存日志 → 
        ↓                    ↓
     风控中心 ←──── 交易日志 → 统计分析 → 复盘中心
```

### GlassStudio 使用流程

```
上传图片 → 选择工具（毛玻璃/文字/卡片）→ 添加元素 → 
    编辑属性（颜色/大小/字体/阴影）→ 调整位置 → 导出高清
```

## 数据管理

- **自动备份**：开启后定期保存至 `trade_auto_backup_*` 键
- **手工备份**：点击「立即备份」下载 JSON 文件
- **数据导入**：通过「导入 JSON」恢复备份数据
- **清空日志**：谨慎操作，不可恢复

## 技术实现

### TradingDiscidence
- **单页应用（SPA）**：通过 nav 切换 `<section>` 视图
- **LocalStorage 持久化**：所有交易数据本地保存
- **纯前端无后端**：所有计算在浏览器完成
- **模块化 JS**：每个功能独立JS文件，通过script标签引入顺序加载

### GlassStudio
- **Canvas 渲染引擎**：所有元素作为绝对定位 div 图层叠加
- **操作历史栈**：JSON 序列化实现 undo/redo
- **拖拽处理**：mousedown/mousemove/mouseup 完整交互链
- **本地字体加载**：通过 `FontFace` API 动态注册用户上传的字体
