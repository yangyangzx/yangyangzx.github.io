# 交易风险控制系统 v5

面向加密货币合约交易的专业风险控制与交易日志系统。以风险控制为核心，提供开仓前仓位计算、风控预警、统计分析、交易复盘的全链路工具。

---

## ✨ 功能概览

### 📊 开仓计划

以风险金额为锚点，反推仓位大小，支持分批建仓和多止盈规划。

| 参数 | 说明 |
|------|------|
| 交易品种 | BTC/USDT、ETH/USDT、SOL/USDT、GOLD/USDT |
| 本金 | 当前账户权益（USDT） |
| 风险比例 | 单笔愿意承担的最大亏损占本金百分比（0.5%-10%） |
| 入场价 / 止损价 | 决定止损距离 |
| 杠杆 | 合约杠杆倍数（0x现货、5x、10x、20x、50x、100x） |
| 止盈价 | 可选，计算盈亏比 |

**输出**：建议仓位（USDT）、实际保证金、盈亏比、止损触发损失、强平价。

**分批建仓**：支持 2-3 批入场，每批独立设入场价和比例，自动计算加权均价并联动下游计算。

**多止盈规划**：自动计算多个目标价格，支持分批止盈。

### 开仓

1. 填写本金（首次自动保存到 localStorage）
2. 选择交易品种、输入入场价、止损价、杠杆、风险比例

1. 在日志列表找到对应条目
2. 点击「平仓」按钮
3. 填写平仓价、平仓类型、情绪标签、盈亏原因
4. 确认平仓 → 盈亏自动计算 → 统计刷新

### 风控监控

- 实时查看账户概览和风险敞口
- 设置日亏损上限和回撤预警阈值
- 监控未平仓仓位的强平价风险

## 📊 核心计算公式

### 仓位计算

```
风险金额 = 本金 × 风险比例%
止损距离 = |入场价 - 止损价|
名义仓位 = 风险金额 × 入场价 / 止损距离
保证金 = 名义仓位 / 杠杆
```

### 强平价计算

```
多单强平价 = 入场价 × (1 - (1 - MMR) / 杠杆)
空单强平价 = 入场价 × (1 + (1 - MMR) / 杠杆)
```

### 加权入场价（分批建仓）

```
加权入场价 = Σ(批次价格 × 批次占比) / Σ(批次占比)
```

### 盈亏比

```
盈亏比 = 目标距离 / 止损距离
```

## 🔒 风险控制体系

### 仓位硬上限

自动考虑已有持仓占用的保证金，确保新开仓位不超过可开仓位上限。

### 连亏熔断

当日连续亏损 ≥3 笔时，禁止计算新仓位，建议暂停交易冷静。

### 连亏调整

连续亏损 ≥3 笔时，自动将仓位降至 60%，强制风险控制。

### 强平价校验

止损价超越强平价时，触发红色预警，提示风险。

### 日亏损监控

当日亏损达到设定上限时，触发进度条预警。

### 回撤监控

最大回撤超过设定阈值时，提示降低仓位或暂停交易。
