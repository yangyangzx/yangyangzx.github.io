# 📊 TradingDiscipline · 交易风险管理终端

**专业期货交易风控与复盘工具 · v5.0-alpha**

面向加密货币/合约交易者的全流程风控系统，覆盖开仓前计算、持仓监控、平仓记录、统计分析、复盘优化五大环节。所有数据本地存储，完全离线运行。

---

## ✨ 核心功能

### 1️⃣ 仓位计算器（开仓前）

以风险金额反向推算理想仓位，支持多种建仓策略：

| 功能 | 说明 |
|------|------|
| **基础计算** | 输入品种、入场价、止损价、本金、风险比例，自动计算仓位大小、保证金、盈亏比 |
| **分批建仓** | 支持 2-3 批入场，每批独立设置价格/比例/止损，自动计算加权均价 |
| **多止盈规划** | TP1/TP2/TP3 三级止盈，自动计算每档盈亏比，手动输入则显示实际值 |
| **盈亏比反推** | 给定目标 R:R，反推止盈价或止损价 |
| **ATR 动态止损** | 输入 ATR 值自动计算止损距离 |
| **凯利公式** | 输入历史胜率/均盈利/均亏损，计算最优仓位比例 |

**风控硬限制：**
- 保证金 ≤ 本金 80%（单笔）
- 总保证金 ≤ 本金 90%（聚合）
- 止损必须在强平价之上/之下
- 连亏 ≥3 笔时仓位降至 60%

### 2️⃣ 开仓前检查清单

点击「计算仓位」后自动运行 11 项检查：

| 检查项 | 说明 |
|--------|------|
| 风险比例合理 | ≤ 设置中的单笔风险比例 |
| 止损距离合理 | ≤ 品种自定义止损比例（如 BTC≤3%，ETH≤2%） |
| 强平安全 | 止损价在强平价之上/之下 |
| 连亏未触发 | 当日连续亏损 < 3 笔 |
| 盈亏比达标 | ≥ 设置中的最低盈亏比（默认 2:1） |
| 保证金合规 | ≤ 本金 50% |
| 入场理由 | 必须有入场理由才能开仓 |
| 日亏损未超限 | 当日亏损 < 日亏损上限 |
| 心态评分 ≥ 3 | 入场前必须评分 |
| 组合热量安全 | 当前热量 < 上限 |
| 品种集中度 | 单品种保证金 ≤ 总本金 X% |

### 3️⃣ 交易日志

完整记录每笔交易的详细信息：

**开仓字段：** 品种、方向、订单类型、入场价、止损价、止盈价、仓位、杠杆、风险额、心态评分、策略框架、形态、信号、交易时段、市场环境、入场理由

**平仓字段：** 平仓类型、平仓价、盈亏金额、R 倍数、手续费、滑点成本、MAE%、MFE%、执行评分、出场理由、亏损原因、交易情绪、平仓备注

**操作功能：** 软删除（5 秒撤销）、批量删除、JSON 导入、CSV 导出、多维度筛选

### 4️⃣ 仪表盘

- **今日盈亏**：实时累计已平仓交易盈亏
- **本周胜率**：周一至今的胜率统计
- **在仓风险**：各持仓保证金占比、强平价距离
- **连亏计数**：当日连续亏损笔数，超限则禁止开仓
- **强平预警**：展示强平价最近的持仓，颜色标记风险等级
- **资金曲线**：Canvas 绘制的权益变化折线图

### 5️⃣ 风控中心

- **账户概览**：总余额、已用保证金、可用余额、风险敞口
- **日亏损监控**：进度条显示当日亏损占日上限比例
- **回撤监控**：当前回撤幅度、最大回撤阈值告警
- **强平一览**：所有未平仓仓位的止损价、强平价、安全距离
- **品种集中度**：按品种统计保证金占比，超限告警
- **热量监控**：当前组合热量（所有未平仓风险之和），超限禁止开仓

### 6️⃣ 统计分析

**综合指标：**
- 已平仓交易数、胜率、总盈亏、平均盈亏、盈亏比

**风险质量指标：**
- 期望值 = 胜率 × 平均盈利 − 败率 × 平均亏损
- 利润因子 = 总盈利 ÷ 总亏损绝对值
- 平均 R 倍数 = 实际盈亏 ÷ 风险额

**持仓管理指标：**
- MAE（最大不利偏移）、MFE（最大有利偏移）、MFE/MAE 比率

**可视化图表：**
- 资金曲线、策略绩效柱状图、形态胜率分布、情绪关联分析、亏损原因饼图、MAE/MFE 散点图、平仓类型分布、每日/每月盈亏图、品种×方向×时段多维拆解

### 7️⃣ 复盘中心

- **策略形态排名**：按胜率排序，找出最优形态
- **情绪关联分析**：不同心态对绩效的影响
- **执行质量分析**：入场评分与实际结果的关联
- **市场环境分析**：不同市场条件下的表现

## ⚙️ 系统设置

所有参数存储在 `localStorage`，可在「系统设置」中修改：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 账户余额 | 0 | 用于计算日亏损上限和热量监控 |
| 单笔风险比例 | 2% | 默认风险比例 |
| 日亏损上限 | 5% | 当日亏损达到此比例禁止开仓 |
| 最大回撤告警 | 20% | 回撤达到此值告警 |
| 最低盈亏比 | 2 | 低于此值交易被标记为不可接受 |
| 品种自定义止损比例 | {} | JSON 格式，如 `{"ETH":2,"BTC":3}`，留空用默认规则 |
| 品种管理 | BTC/ETH/SOL/GOLD | 管理下拉选项列表，支持手动输入任意品种 |
| 心态评分最低通过 | 3 | 低于此值标记警告 |
| ATR 动态止损 | 关 | 启用后自动以 ATR×倍数 作为止损距离 |
| ATR 默认倍数 | 2 | ATR 模式下默认倍数 |
| 组合热量上限 | 8% | 所有未平仓持仓风险之和的百分比上限 |
| 组合热量安全上限 | 6% | 达到此值警告，超过则禁止开仓 |
| 单品种最大占比 | 10% | 单品种保证金占总本金上限 |
| 日最大交易笔数 | 8 | 达到此笔数触发频率警告 |
| 维持保证金率 | 0.5% | 强平计算参数 |
| 默认杠杆 | 10 | 计算器默认杠杆 |

## 🧮 核心公式

```
仓位大小     = 风险金额 × 有效入场价 / 止损距离
风险金额     = 本金 × 风险比例
止损距离     = |有效入场价 - 止损价|
有效入场价   = 入场价 × (1 ± 滑点率)    [滑点率: 市价 0.1%, 止损单 0.2%, 限价 0]
盈亏比       = (目标价 - 有效入场价) / 止损距离   [净盈亏比扣除手续费]
强平价(多)   = 入场价 × (1 - 1/杠杆) / (1 - MMR)
强平价(空)   = 入场价 × (1 + 1/杠杆) / (1 + MMR)
R 倍数       = 净盈亏 / 风险额
期望值       = 胜率 × 平均盈利 - 败率 × 平均亏损
利润因子     = 总盈利 / 总亏损绝对值
```

## 🎯 设计理念

1. **风险控制优先** — 任何交易前必须通过检查清单
2. **数据驱动决策** — 所有参数可配置，统计结果可追溯
3. **本地隐私安全** — 数据完全存储在浏览器，不上传任何信息
4. **闭环交易管理** — 从开仓计划到复盘分析的完整闭环

## 📖 使用流程

```
系统设置 → 配置风控参数 → 开仓计划 → 填写参数 → 计算仓位 → 检查清单
                              ↓

```
